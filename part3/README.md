# Phonebook Backend

Backend for the Phonebook application built with Node.js and Express.

## Online Application

[Phonebook Backend](YOUR_RENDER_URL)

## API

* `GET /api/persons` — Get all persons
* `GET /api/persons/:id` — Get a person
* `POST /api/persons` — Add a person
* `DELETE /api/persons/:id` — Delete a person

## Technologies

* Node.js
* Express
* MongoDB
* Render
